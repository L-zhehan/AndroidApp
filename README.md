# 💰 简易个人记账本 (Personal Record App)

本项目是《金融软件开发与应用》课程的结课大作业。使用 **Android Studio** 和 **Java** 语言开发的一款轻量级、界面现代化的个人记账 APP。

## 📝 项目简介
本软件旨在帮助用户快速记录日常生活中的各项收支。摒弃了繁琐的注册登录流程，主打“打开即记，退出即清”的轻量级演示理念。软件拥有极简的卡片式 UI 设计，支持动态切换的收支分类，并能实时统计总收入与总支出。

---

## ✅ 课程考核要求对应说明
本项目严格按照期末考核标准开发，包含了所有必做与选做要求：

1. **多 Activity 与 传值**：包含 `MainActivity`（记账页）和 `ResultActivity`（账单页），通过 `Intent` 与 `Bundle` 实现了页面跳转及最新记录的数据传值。
2. **基础控件交互**：`TextView` (展示信息)、`EditText` (输入金额，支持小数)、`Button` (保存记录) 均具备完善的事件监听与交互逻辑。
3. **静态姓名学号**：在两个页面的顶部均使用 `TextView` 静态写死了开发者姓名与学号，运行时不可编辑。
4. **备选控件选用 (≥4种)**：
   * **RadioGroup / RadioButton**：用于选择“支出”或“收入”。
   * **Spinner**：用于选择具体的消费/收入类别（支持随 RadioGroup 动态切换）。
   * **ListView**：用于在结果页渲染历史账单列表。
   * **ImageButton**：用作结果页底部的全宽大号返回按钮。

---

## ✨ 核心功能特性
* **动态分类联动**：选择“支出”时，下拉框提供（餐饮、娱乐、日用、服饰、交通、学习、社交、其他）；选择“收入”时，下拉框自动切换为（工资、理财、报销、奖金、其他）。
* **实时统计面板**：结果页会根据列表中的历史记录，自动遍历计算并展示当前的“总支出”和“总收入”。
* **现代化 UI 设计**：采用 Material Design 风格，包含圆角卡片（`CardView` 形状背景）、主题色背景、大触控区域按钮，提升用户体验。
* **内存级数据管理**：数据通过 `public static List` 存储在内存中，方便在多个 Activity 间共享。彻底关闭 App 后数据清空，完美契合课程演示需求，无需引入复杂的数据库。

## 🛠️ 核心技术点与踩坑记录

### 1. 解决 Android 12+ 原生 Spinner 点击失效 Bug
在较高版本的 Android 模拟器（如 API 31+）中，默认的 Material 主题会导致 `Spinner` 的触摸事件失效，用户必须按住拖拽才能勉强选中。
**解决方案**：在代码中为 Spinner 强制添加触摸拦截，绕过系统的底层判定：
```java
spinner.setOnTouchListener((v, event) -> {
    if (event.getAction() == MotionEvent.ACTION_UP) {
        spinner.performClick(); // 强制触发点击事件弹出下拉列表
    }
    return true;
});
```
